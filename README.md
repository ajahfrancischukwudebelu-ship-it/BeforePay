# BeforePay MVP

This is the first free prototype of BeforePay.

Files:
- index.html — website
- style.css — design
- app.js — working preliminary risk checker

The checker is a browser-only rule-based prototype. It does not prove that a person or business is fraudulent or legitimate and does not perform live web/database checks.

Open index.html in a browser to test it.

Next production steps:
1. Free web hosting.
2. Secure backend/database.
3. Moderated community reports.
4. Legitimate public-web/business verification.
5. Stronger evidence-based scoring.
6. Paid detailed reports/business plans after validation.
